# Upgrade Educação

Projeto

Desenvolva um MVP completo chamado Upgrade Educação.

Slogan:

Aprendizado que vira oportunidade.

A identidade visual deve utilizar como referência a logomarca fornecida, preservando as cores institucionais (azul escuro e verde), utilizando uma interface moderna, limpa, profissional e inspirada em plataformas como LinkedIn, Coursera, Notion e Stripe.

A aplicação deve ser totalmente responsiva.

Objetivo da plataforma

A Upgrade Educação não é apenas uma plataforma de cursos.

Ela é um Hub de Skills Intelligence.

Nossa missão é conectar educação, empregabilidade e empresas através das competências desenvolvidas pelos usuários durante sua trajetória acadêmica.

Os cursos assistidos, certificados obtidos, testes comportamentais e demais atividades constroem continuamente um perfil inteligente de competências.

Esse perfil será utilizado pelo motor de matching para sugerir oportunidades de trabalho compatíveis.

A plataforma nunca toma decisões de contratação.

Ela apenas conecta talentos e oportunidades.

Toda decisão permanece com o usuário e com a empresa.

Objetivo final

Construir um MVP de um SAAS navegável e funcional que demonstre que a Upgrade Educação é uma plataforma de Skills Intelligence, onde a educação gera competências verificadas e essas competências alimentam um motor de empregabilidade responsável, transparente e centrado no usuário, respeitando os princípios de privacidade, agência humana e transparência definidos na arquitetura da plataforma.

Em anexo tem nossas logos, nosso AIA, uma sintese de o que é a upgrade, e o roteiro dos videos (parametro)
